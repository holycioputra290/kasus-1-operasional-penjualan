# 🍎 Dashboard Operasional Penjualan (Kasus 1)

Aplikasi web dashboard interaktif berbasis **Streamlit** dan **Plotly** dengan antarmuka **Apple UI / macOS Style** untuk menganalisis data operasional penjualan (`dataset_operasional_penjualan.csv`).

## 🛠️ Fitur Utama
- **Filter Interaktif:** Filter berdasarkan rentang tanggal, kategori produk, dan spesifik produk.
- **KPI Metrics Cards:** Informasi Total Pendapatan, Total Unit Terjual, Rata-rata Transaksi, dan Jumlah Transaksi.
- **Visualisasi Interactive:**
  1. Tren Penjualan Harian (Spline Line Chart)
  2. Proporsi Kategori (Donut Chart)
  3. Total Terjual per Produk (Bar Chart)
  4. Distribusi Harga Produk (Histogram)
